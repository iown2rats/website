# Prototype (design source of truth)

Unmodified copies of the supplied Thundi prototype. Do not edit these files.

- `Thundi.dc.html` — Claude Design template + logic (current, compact revision)
- `thundi-data.js` — demo profiles, chats, posts, locations, interests, prompts
- `support.js` — dc-runtime needed only to render the prototype (React 18 UMD from unpkg)

To view locally: serve this folder over HTTP (e.g. `npx http-server prototype -p 8123`) and open `Thundi.dc.html`.
The audit is in `docs/PROTOTYPE_AUDIT.md`; rendered reference sheets are in `docs/prototype-reference/`.
